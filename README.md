# POKE-MAN

포켓몬 캐릭터로 즐기는 팩맨 게임입니다. (Windows용, 파이썬 설치 필요 없음)

> **비공식 팬 프로젝트입니다.** 포켓몬 및 관련 캐릭터·명칭은 Nintendo, Creatures Inc., GAME FREAK inc., The Pokémon Company의 자산이며,
> 이 프로젝트는 그 회사들과 무관하고 승인받은 것이 아닙니다. 상업적 목적 없이 개인적으로 만든 것입니다. 모든 그림은 이미지 파일 없이 코드로 직접 그렸습니다.
> *Unofficial fan project, not affiliated with or endorsed by Nintendo, Creatures, GAME FREAK or The Pokémon Company. Non-commercial.*

## 다운로드와 실행

1. 오른쪽 **Releases**에서 exe 파일을 내려받습니다.
2. 더블클릭하면 바로 시작합니다. 설치도, 파이썬도 필요 없습니다. (Windows 10/11 64비트, 시작까지 약 1~2초)

**"Windows의 PC 보호" 창이 뜰 때**: 이 프로그램은 개인이 만든 것이라 디지털 서명이 없어서 Windows SmartScreen이 경고를 띄웁니다.
**「추가 정보」 → 「실행」** 을 누르면 됩니다. 걱정되면 아래 체크섬으로 파일이 그대로인지 확인하세요.
일부 백신이 이 종류의 프로그램(PyInstaller로 만든 exe)을 잘못 의심할 수 있습니다.

> 최고 점수 파일(`highscore_pokemon.txt`)이 exe 옆에 저장됩니다. `Program Files`처럼 쓰기 권한이 없는 폴더가 아닌 곳(바탕화면, 다운로드 등)에 두세요.

## 게임 소개

- **캐릭터 5종**: 피카츄, 메타몽, 파이리, 꼬부기, 이상해씨 (멀티플레이에서는 같은 캐릭터를 여럿이 골라도 됩니다)
- **고스트 = 로켓단** (무사시, 나옹, 코지로, 마자용), **열매 = 몬스터볼**
- **1인용**
  - 클래식 10스테이지: 원작 미로 포함, 뒤로 갈수록 어려워집니다
  - 랜덤 100단계: 매번 새로운 미로가 만들어집니다. 1단계는 아주 쉽고 100단계까지 조금씩 어려워집니다. 막다른 길은 없습니다
- **멀티플레이** (같은 네트워크에서)
  - **협동** 2~4명: 한 화면에서 함께 플레이, 점수와 예비 목숨을 공유합니다
  - **경쟁** 2명: 각자 자기 판을 플레이하고, 화면에 **내 판과 현재 1등의 판**이 나란히 나옵니다 (내가 1등이면 2등의 판)
  - 플레이어는 P1~P4 색과 표시로 구분됩니다

## 조작

| 키 | 동작 |
|---|---|
| 방향키 / WASD | 이동 |
| ↑ ↓ / ← → | 메뉴 선택 / 캐릭터 고르기 |
| Enter / Space | 확인, 시작 |
| P | 일시정지 (멀티플레이는 호스트만) |
| M | 소리 켜기/끄기 |
| Esc | 뒤로 (시작 화면에서는 종료) |

## 멀티플레이 방법

**방 만들기**: 시작 화면에서 `MULTIPLAYER` → `HOST A GAME` → 방식(협동/경쟁)·스테이지·내 캐릭터를 고르고 방을 엽니다.
화면에 내 IP가 나옵니다. 친구가 들어오면 Enter로 시작합니다.

**참가하기**: `MULTIPLAYER` → `JOIN A GAME`. 같은 네트워크의 방이 목록에 자동으로 뜹니다.
안 보이면 `TYPE AN IP ADDRESS`를 골라 호스트가 알려준 IP를 직접 입력하세요.

- 호스트가 처음 방을 열면 **Windows 방화벽 창이 뜹니다. 「개인 네트워크」를 허용**해야 다른 사람이 접속할 수 있습니다.
- 같은 공유기(와이파이) 안에서만 됩니다. 기기 간 통신을 막아 둔 학교·회사 네트워크에서는 안 될 수 있습니다.
- 사용하는 포트: TCP/UDP **47800**
- VPN을 쓰면 다른 IP가 표시될 수 있습니다. 그때는 실제 LAN IP를 직접 입력하세요.
- 잡히면 죽는 연출 뒤 2.5초 보호를 받으며 되살아납니다. 다른 사람은 끊기지 않고 계속 플레이합니다.
- 경쟁 모드에서는 창이 잠깐 깜빡이며 두 배로 넓어집니다. 정상입니다.

## 알아둘 점

- 소리는 **오디오 출력 장치가 있는 PC에서만** 납니다. 멀티플레이에서는 호스트 컴퓨터에서만 소리가 납니다.
- 멀티플레이는 한 PC 안에서 여러 프로그램을 띄워 시험했고, 실제로 컴퓨터 여러 대를 연결한 시험은 충분하지 않습니다. 문제가 있으면 알려 주세요.

## 파일 확인 (SHA-256)

내려받은 exe가 그대로인지 확인하려면 PowerShell에서 아래를 실행하고 값을 비교하세요.

```powershell
Get-FileHash .\내려받은파일이름.exe -Algorithm SHA256
```

```
5ABD0467BFA909C1D8EAD03581739BA477D3A66C2521A8A255B7FBD8AC317716
```

(파일 크기 16,145,096바이트. exe를 다시 만들면 이 값이 바뀌므로 README도 함께 고쳐 주세요.)
